# Mini Message Board

A small message board built with Node.js, Express, and EJS as part of The Odin Project curriculum.

## Features

- View all messages
- Add a new message
- Open an individual message
- Display the author and creation date

## Technologies

- Node.js
- Express
- EJS
- HTML
- CSS

## Run locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open this address in your browser:

```text
http://localhost:3000
```

## Data storage

Messages are stored in an in-memory array. Messages added through the form are cleared whenever the server restarts.
